# Simple Task Tracker

Build a small web app for managing daily tasks.

## Features
- Add a task with a title.
- Mark tasks as completed or incomplete.
- Delete a task.
- Filter tasks by All, Active, and Completed.
- Show the number of incomplete tasks.
- Save tasks in browser localStorage so they survive a refresh.

## Technology
Use React with Vite and plain CSS. No backend, login, database, or external APIs.

## Design
A clean, responsive page with a heading, task input, Add button, filter buttons, and task list.

## Acceptance Criteria
- Empty task titles cannot be added.
- Adding a task clears the input.
- Completing, deleting, and filtering tasks work correctly.
- Tasks remain saved after refreshing.
- The page works on mobile and desktop.

## Department Work
- Engineering: implement the app.
- Design: create a simple, accessible layout.
- QA: verify the acceptance criteria.
- Other departments: no work required for this project.
